Published on Roblox as **"Star RNG"** (owner account: plzpetplznoobb2). Repo: `fara-art/rolboxfi`,
working branch `claude/wizardly-pascal-g6tfoq`. Commit + push after every finished piece of work.

## Working with the owner
- Talk in **Russian**, casual "браток" tone, short and to the point. Don't just agree: if an idea is
  bad or risky (copyright, Roblox rules, money), say so and offer a better option.
- The **game itself is in English + Russian** (language toggle). All player-facing text lives in `src/shared/Lang.luau`.
- The owner tests in **Roblox Studio on Windows**, often behind a VPN (Roblox is blocked in Russia).
  He does NOT use Rojo: after every change rebuild the place file and send it with SendUserFile.
- He can't read code; ask for **screenshots + red/yellow lines from Output** when something breaks.
- Never use images/sounds from the internet (copyright strikes). All art/audio is generated by our scripts.

## Build / deliver
- `python3 tools/build_place.py` → `ConstellationsRNG.rbxlx` (all scripts embedded, no Rojo needed).
  Owner opens it, tests, then File → Publish to Roblox As → Star RNG.
- Rojo project also exists (`default.project.json`), mapping src/shared → ReplicatedStorage.Shared,
  src/server → ServerScriptService.Server, src/client → StarterPlayerScripts.Client.
- No Luau compiler here (running downloaded binaries is blocked). Before shipping always run
  `python3 tools/check_forward_refs.py src/client/*.luau src/server/*.luau src/shared/*.luau`
  and `python3 tools/check_locals.py src/*/*.luau` (Roblox limit: 200 locals/registers per chunk —
  Main.client hit it once and the whole UI died; new sections go inside `do ... end`),
  and re-read edited code. Past bugs worth remembering:
  - a local function used before its `local` declaration → nil global at runtime;
  - GUI made without `Parent = gui` → invisible windows;
  - `ScreenPointToRay` for InputObject.Position, `ViewportPointToRay` for GetMouseLocation;
  - GUI rotates around the element centre (not AnchorPoint);
  - `workspace.FallenPartsDestroyHeight` is not scriptable (crashed the server once);
  - Luau if-expression returns ONE value (`local a, b = if c then f() else nil, nil` is wrong).

## Code map
- `src/shared/Stars.luau` — 77 stars ordered by rarity (`chance` = 1 in N, `income`/s, `kind` for named stars).
- `Mutations.luau` — Shiny/Golden/Void/Celestial: NOT rolled, crafted at the Forge
  (copies 2/2/3/5, rarity & income x1.5/x3/x10/x50).
- `Items.luau` — item key `"starId"` or `"starId|mutationId"`.
- `Config.luau` — all balance: luck, roll speed, multi roll, slabs, museum floors, themes, rebirth,
  index tiers (9 stars each, auto-built), roll milestones, alert thresholds, icon/sound IDs, admins.
- `Odds.luau` (rolls + honest odds), `Sky.luau` (income of placed stars; constellations disabled by flag),
  `Evolution.luau` (stars age on stands: levels 1-5, some explode into better stars), `Format.luau` (K M B T Qd Qn …).
- `src/server/Main.server.luau` — remotes, sessions, roll, all actions (validated server-side), income tick,
  admin actions (owner only / Studio), star shower, leaderboard loop.
- `World.luau` — builds the map at runtime: hub (fountain, forge house, leaderboard tablets), Black Hole island
  (meteors, vortex, lava), 7 plots with **museums** (20 wall spots per floor, up to 5 floors, elevator, themes).
- `StarModels.luau` — 3D star on a stand (builder per star id or per `kind`), client spins them via attribute `Base`.
- `DataService.luau` — DataStore save/load + defaults (add new fields there; old saves get reconciled).
- `Leaderboards.luau` — global top-100 (OrderedDataStore `LB_*_v2`), drawn on stone tablets by the client.
- `src/client/Main.client.luau` — the whole UI (light cartoon theme, icon buttons, one window at a time),
  build mode (hover/confirm), big reveal cinematic, leaderboards SurfaceGuis, sprint, settings, admin panel.

## Robux shop (src/shared/Config.luau → Config.Shop)
Developer Products: crate x1/x3/x10 (odds shown in the shop — Roblox rule for paid random items),
x2 luck and x2 roll-speed boosts for 15/30/60 min, permanent speed tiers (6) and multi-roll tiers (5) with rising prices.
`id = 0` = not created yet: in Studio the buttons grant for free (action ShopTest), live servers show "not set up".
Owner must create every product in Creator Hub (Monetization → Developer Products) and send the IDs.
ProcessReceipt is idempotent (data.receipts).
