# Созвездия RNG

Roblox RNG-игра: крутишь звёзды, расставляешь на небе, собираешь созвездия, получаешь доход.

## Механика
- **Крутка** (1 раз/сек): 9 звёзд, от «Пыли» (1 к 2) до «Сверхновой» (1 к 1 000 000)
- **Небо**: сетка 4×4 (расширяется до 8×8). Звезда на небе приносит доход/с
- **Созвездия**: отдельная группа звёзд (соседи и по диагонали) точной формы
  даёт множитель. Лишний сосед ломает фигуру, поэтому думать, куда ставить, обязательно
- **Чистое созвездие**: все звёзды одного типа, ещё x1.5
- **Улучшения за кэш**: удача +0.25, расширение неба
- **Звездопад**: каждые 10 мин удача x2 на 3 мин всему серверу
- **Объявления**: звёзды от 1 к 10 000 и первые открытия созвездий
- **Шансы** показываются честно (точные проценты с учётом удачи)
- **Мутации**: Shiny / Golden / Void / Celestial, отдельный ролл, множитель дохода
- **Кузня**: 5 одинаковых звёзд + кэш → 1 звезда следующего уровня (мутация сохраняется)
- **Эволюция**: звёзды на небе растут до 5 уровня (x3), Солнце/Гигант/Квазар могут взорваться в звезду получше
- **Чёрная дыра**: скармливаешь звёзды → масса → ребёрт (x доход, + удача навсегда)
- **Кометы**: пролетают по экрану, клик = крутка с x5 удачей

## Карта
Хаб в центре (Чёрная дыра с алтарём, Звёздная кузня, Обсерватория) + 8 участков на мостах.
Над участком висит 3D-небо игрока, созвездия соединены линиями. Карта строится скриптом `src/server/World.luau`.

## Структура
```
src/shared   -> ReplicatedStorage.Shared   (звёзды, созвездия, конфиг, логика)
src/server   -> ServerScriptService.Server (крутка, сохранения, доход)
src/client   -> StarterPlayerScripts.Client (интерфейс)
```
Баланс правится в `src/shared/Config.luau`, `Stars.luau`, `Constellations.luau`.

## Быстрый запуск (без Rojo)
Открыть `ConstellationsRNG.rbxlx` в Roblox Studio → Play.
После правок в `src/` пересобрать: `python3 tools/build_place.py`.

## Запуск через Rojo
1. Поставить [Rokit](https://github.com/rojo-rbx/rokit), в папке проекта: `rokit install`
2. В Roblox Studio поставить плагин Rojo
3. `rojo serve`, в Studio: плагин Rojo → Connect
4. Game Settings → Security → включить **Enable Studio Access to API Services** (для сохранений)
5. Play

## Геймпассы
Создать на create.roblox.com и вписать ID в `Config.GamePasses`:
`Luck2x`, `Cash2x`, `AutoRoll` (пока ID = 0, автокрутка бесплатная для тестов).
